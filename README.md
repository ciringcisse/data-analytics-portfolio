# Ciring Cisse — Data Analytics Portfolio

A CV-focused portfolio website for Power BI and data analytics work.

## Pages

- `index.html` — homepage
- `finance.html` — Finance Performance Dashboard case study
- `customers.html` — Customer & Sales Dashboard case study
- `suppliers.html` — Supplier Performance Dashboard case study

The case-study pages are intentionally built as if the portfolio is already live. Dashboard areas are placeholders ready for:
- Power BI embeds
- Dashboard screenshots
- KPI explanations
- SQL / DAX snippets
- Business insights

## Publish

Create a GitHub repository, upload all files/folders, then:

Settings → Pages → Deploy from a branch → main → /(root)

## Important

Do not publish confidential employer data. Use synthetic or anonymised data for public case studies.
